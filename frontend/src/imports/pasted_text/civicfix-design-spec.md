Design a polished, modern, human-designed web application called **CIVICFIX — AI-Powered Urban Issue Detection, Prioritization & Resolution Platform**.

CIVICFIX is a civic-tech platform that connects citizens with municipal authorities to report, verify, prioritize, assign, track, and resolve urban problems such as potholes, damaged roads, broken streetlights, overflowing garbage bins, water leakage, blocked drains, and fallen trees.

### Overall Design Direction

Create a website that feels like a **real product built by a professional startup team**, not an AI-generated template.

The design should be:

* Clean and minimal
* Trustworthy and government-friendly
* Modern but not overly futuristic
* Human-centered
* Easy to understand at first glance
* Visually polished with realistic spacing and hierarchy
* Accessible for people of different ages and technical abilities

Avoid excessive gradients, excessive glassmorphism, neon colors, unnecessary animations, oversized text, and too many cards.

Use a **light interface** with an off-white/light gray background and a strong civic-tech color palette:

* Deep navy/blue for trust and navigation
* Green for resolved/success states
* Amber/orange for warnings and medium priority
* Red only for urgent/high-priority issues
* White surfaces with subtle borders and shadows

Use typography similar to **Inter, Manrope, or another clean modern sans-serif**.

Use realistic UI details throughout:

* Consistent border radius around 10–14px
* Subtle shadows
* Thin borders
* Clear hover states
* Proper empty states
* Loading states
* Success notifications
* Error messages
* Confirmation dialogs
* Responsive layouts
* Accessible contrast
* Realistic map UI

Use icons from a consistent icon family such as Lucide.

Do NOT use random emoji as interface icons.

---

# RESPONSIVE DESIGN

Design the system primarily for desktop but ensure it adapts to tablet and mobile.

Mobile navigation should become a bottom navigation or hamburger menu.

Citizen reporting should be especially easy on mobile because users may report an issue directly from the street.

---

# HUMAN-DESIGNED PRINCIPLES

The final interface must NOT look like a generic AI-generated dashboard.

Avoid:

* Huge rounded cards everywhere
* Excessive gradients
* Neon blue/purple AI aesthetics
* Too many floating elements
* Random decorative shapes
* Excessive glassmorphism
* Unnecessary 3D illustrations
* Generic stock photography
* Too many colors
* Overloaded dashboards

Instead prioritize:

* Clear hierarchy
* Realistic municipal workflows
* Meaningful information
* Practical interactions
* Consistent spacing
* Strong typography
* Subtle visual personality
* Real-world usability

The final result should look like a **production-ready civic technology platform that could realistically be presented to a municipal corporation, hackathon jury, or startup investor.**

Create the Figma design with reusable components, consistent styles, buttons, cards, badges, navigation, forms, tables, maps, charts, modals, and responsive layouts.
